# Prompt examples

## General agent

```bash
~/kaliarc-ai-lab/bin/general-agent.sh "Create a 30-day Linux learning plan"
```

## Code agent

```bash
~/kaliarc-ai-lab/bin/code-agent.sh --file ./install.sh "Review this script for portability and error handling"
```

## KaliGPT local

```bash
~/kaliarc-ai-lab/bin/kali-gpt-local.sh "Explain how systemd services work on Kali"
```

## Report agent

```bash
~/kaliarc-ai-lab/bin/report-file.sh ~/kaliarc-ai-lab/reports/nmap-YYYYMMDD-HHMMSS.nmap
```
