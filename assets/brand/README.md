# Brand assets

This folder contains SVG branding assets for **KaliArc AI Lab**.

| Asset | Use |
|---|---|
| `logo.svg` | Full horizontal logo for README headers |
| `logo-mark.svg` | Square icon/avatar |
| `banner.svg` | Social preview / repository banner |
| `readme-hero.svg` | README hero panel |

All assets are generated as plain SVG files so they render directly on GitHub without external image hosting.
