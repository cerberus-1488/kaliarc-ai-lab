# Changelog

## 0.1.0

Initial GitHub-ready release.

- Core installer for Docker, Ollama, Open WebUI, LiteLLM, Qdrant, SearXNG, n8n, and Flowise.
- Default Ollama model pulls including `llama3:latest` and `mistral:latest`.
- Local multi-agent workflow.
- Local general, code, sysadmin, report, and KaliGPT-style launchers.
- Scoped Kali tool wrappers.
- Optional HexStrike local MCP wiring.
- XDG/Kali AI Lab menu entries.
- GitHub Actions shellcheck workflow.
- SVG screenshots and architecture diagram.
